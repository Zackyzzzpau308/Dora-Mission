# Dora-Mission
READ-ME: Misi Membaca Bersama Dora ialah permainan pendidikan interaktif bertemakan pengembaraan yang membantu murid menguasai sebutan, ejaan dan intonasi yang betul melalui pelbagai cabaran membaca. Murid akan mengembara bersama Dora, menyelesaikan misi, mengumpul bintang dan meningkatkan kemahiran membaca secara menyeronokkan.
